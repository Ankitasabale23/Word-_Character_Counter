# Word and Character Counter

## 1. Objective

The objective of this task is to create a Python program that accepts a paragraph and calculates the number of characters, words, sentences, and spaces.

## 2. Tools Used

- Python
- Visual Studio Code
- GitHub

## 3. Programming Language

Python

## 4. Description

This project is a simple text analysis program developed using Python.

The program accepts a paragraph from the user and calculates basic text statistics such as the number of characters, words, sentences, and spaces.

The program also handles empty input.

## 5. Features

- Count total characters
- Count words
- Count sentences
- Count spaces
- Handle empty input
- Display calculated text statistics

## 6. Sample Execution

```text
Enter a paragraph: Python is easy to learn. It is useful for programming!

----- Text Statistics -----
Characters: 57
Words: 10
Sentences: 2
Spaces: 9
